# Dashboard Screenshots and Visualisations

This folder contains visual representations of the Power BI dashboards developed for the Nigeria 2023 Presidential Election Analytics project.

## Individual State Dashboards

Screenshots of the six independently analysed states:

- Lagos
- Kaduna
- Kano
- Oyo
- Enugu
- Rivers

## Consolidated Six-State Dashboards

The five interactive dashboard modules developed to provide a comparative analysis of all six states.

## Purpose

These visualisations demonstrate the analytical process, dashboard development, data storytelling and insights generated throughout the project.
