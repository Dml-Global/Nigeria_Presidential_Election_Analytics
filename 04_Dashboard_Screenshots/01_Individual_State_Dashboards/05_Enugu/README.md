
# Enugu State Election Analysis

This folder contains the five Power BI dashboards developed for the analysis of Nigeria's 2023 Presidential Election in Enugu State.

The dashboards examine electoral performance, voter participation, party distribution, polling-unit data quality and election-related patterns.
