
# Nigeria Presidential Election Analytics (2023)

## Project Overview

This project presents a comprehensive Power BI analysis of Nigeria's 2023 Presidential Election, focusing on six selected states: Lagos, Kaduna, Kano, Oyo, Enugu and Rivers.

The project uses electoral data analysis and interactive visualisations to examine voting patterns, party performance, voter participation, electoral outcomes and polling-unit data quality.

The analysis is organised into individual state-level investigations and a consolidated six-state analysis to provide both local and comparative insights into the election.

## Project Objectives

- Analyse presidential election results across six Nigerian states.
- Compare political party performance and voting patterns.
- Examine voter turnout and participation gaps.
- Identify polling-unit anomalies and potential data-quality issues.
- Compare electoral outcomes across the selected states.
- Present findings through interactive Power BI dashboards.
