This section presents a comparative analysis of Nigeria's 2023 Presidential Election across six selected states: Lagos, Kaduna, Kano, Oyo, Enugu and Rivers.

The six individual state datasets were brought together to examine broader electoral patterns, party performance, voter participation and electoral data quality.
