# Project Documentation

This folder contains the technical documentation and analytical explanations supporting the Nigeria 2023 Presidential Election Analytics project.

## Documentation Contents

### 1. Project Overview
Background, purpose, scope and objectives of the project.

### 2. Data Preparation and Methodology
Explanation of data organisation, cleaning, transformation and preparation for analysis.

### 3. Data Modelling and DAX
Documentation of Power BI data modelling, calculated measures, DAX formulas and analytical calculations.

### 4. Dashboard Development
Explanation of the five consolidated dashboards, their visualisations, interactive features and analytical purposes.

### 5. Key Findings and Insights
Summary of electoral patterns, party performance, voter participation and data-quality concerns identified across the six states.

### 6. Limitations and Recommendations
Discussion of analytical limitations, data reliability considerations and recommendations for further investigation.
