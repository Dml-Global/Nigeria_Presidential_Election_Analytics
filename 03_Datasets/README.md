# Project Datasets

This folder contains the datasets used for the Nigeria 2023 Presidential Election Analytics project.

The project covers six states:

- Lagos
- Kaduna
- Kano
- Oyo
- Enugu
- Rivers

The datasets support individual state analysis and consolidated comparative analysis.

## Data Preparation

Data preparation involved organising election results, reviewing polling-unit records, identifying data-quality issues and preparing the information for analysis in Microsoft Power BI.

## Data Privacy and Usage

Only datasets appropriate for public portfolio sharing will be included.
